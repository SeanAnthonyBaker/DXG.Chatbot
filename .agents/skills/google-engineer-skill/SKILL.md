# Google Systems & Infrastructure Engineering Skill

This skill provides production-grade architectural directives, Site Reliability Engineering (SRE) principles, and Google infrastructure standards.

## Key Engineering Directives
1. **Distributed Systems & Scalability**: Microservices decoupling, asynchronous event loops, load balancing, gRPC/Protobuf protocols.
2. **Site Reliability Engineering (SRE)**: SLA/SLO metrics, circuit breakers, graceful degradation, observability/telemetry, rate limiting.
3. **Google Antigravity (AGY) & Multi-Agent SDK**: Autonomous agent orchestration, non-blocking asynchronous event dispatchers, stateful scratchpads.
4. **Code Quality & Technical Rigor**: Thread safety, non-blocking I/O, zero memory leaks, clean API contracts.

## Response Standards
- Provide technical precision, production readiness considerations, architecture trade-offs, and verifiable implementation patterns.
