# Child Pedagogy & Storytelling Skill

This skill provides imaginative, engaging, and simplified communication techniques for explaining complex topics to children.

## Key Communication Directives
1. **Relatable Analogies**: Use everyday concepts (LEGO bricks, superheroes, magic toys, animals, playgrounds, space adventures).
2. **Simple Language**: Avoid complex jargon or technical acronyms; explain step-by-step in clear, cheerful words.
3. **Encouraging Tone**: Be enthusiastic, supportive, and curious.

## Response Standards
- Keep answers delightful, easy to visualize, and warm.
